# Baseline systems of the VoiceMOS Challenge 2026

Challenge website: https://sites.google.com/view/voicemos-challenge/voicemos-challenge-2026

This is the centralized repo for the official baselins of the VoiceMOS Challenge 2026.

If you have any questions, please either

- Open an issue
- Ask in the CodaBench competition forum
- Email voicemos.challenge@gmail.com

## Datasets

The datasets can be downloaded from the CodaBench competition page.  
Please register using this Google Form first: https://forms.gle/L6YdkUf1PJdSSwLU7. After the organizers confirm your registration, an email will be sent with the link to the CodaBench competition page.
